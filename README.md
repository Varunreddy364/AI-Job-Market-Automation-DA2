# AI Job Market Automation Risk Prediction

## Overview
This project analyzes the impact of Artificial Intelligence on the global job market and predicts the automation risk associated with different occupations using machine learning.

## Dataset
- Source: Kaggle
- Records: 5,000
- Features: 22

## Objectives
- Analyze AI job market trends
- Perform data preprocessing
- Explore relationships between job attributes
- Predict automation risk
- Identify important factors affecting AI-driven job displacement

## Technologies
- R
- RStudio
- Data Cleaning
- Exploratory Data Analysis
- Machine Learning
- Data Visualization

## Workflow
1. Data Cleaning
2. Missing Value Handling
3. Exploratory Data Analysis
4. Feature Engineering
5. Machine Learning Model
6. Result Analysis

## Results
The project identifies the major factors affecting automation risk and provides insights into career sustainability, AI adoption, and workforce reskilling.
